أثير AI — v48 Fast Router

هذه النسخة مبنية على الملف الذي رفعته، مع إبقاء واجهة التطبيق والبحث والتفكير والصور كما هي، وإضافة التبديل التلقائي من داخل Worker.

التوجيه التلقائي:
- سؤال عادي/سريع → @cf/openai/gpt-oss-20b
- زر «تفكير» أو سؤال معقد/برمجي/تحليلي → @cf/openai/gpt-oss-120b
- صورة → @cf/google/gemma-4-26b-a4b-it
- عند تعذر النموذج بسبب السعة/الخطة/التوفر → ينتقل تلقائياً إلى نموذج احتياط مناسب.
- زر «بحث» يبقى كما هو، والـWorker يجلب نتائج الويب ثم يمررها للنموذج المناسب.
- اختيار نموذج يدوي من نافذة النماذج يعطل الوضع التلقائي لهذا الاختيار فقط. يمكن العودة إلى «أثير — تلقائي ذكي» من نفس نافذة النماذج.

مهم:
1) ارفع worker.js الجديد إلى Cloudflare Worker واضغط Deploy؛ هذا الإصلاح ضروري لتقليل التأخير.
2) ارفع app.js الجديد مع index.html وstyle.css.
3) لا تضع Account ID أو API Token داخل التطبيق؛ الاتصال يتم عبر رابط الـWorker الموجود في app.js.
4) Workers AI لديه حصة مجانية يومية من Neurons، وبعض النماذج قد لا تكون متاحة في حساب/وقت معين؛ لذلك أضيف fallback حقيقي داخل Worker.

ملاحظة عن الصور:
التحليل النهائي يتم داخل Cloudflare Worker باستخدام نموذج الرؤية في Workers AI. لا يحتاج مسار Groq الصامت القديم لتحليل الصور عند استخدام Cloudflare.
